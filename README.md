# ЛГП-50: влияние регулируемых фрикционных тормозов на кинематику — доработанная статья и расчёты

Доработанная версия статьи (15 страниц A4) и расчёты, на которых она основана. Версия статьи для открытой публикации не содержит абсолютных размеров и координат установки.
Цепочка расчётов: 3D-модель → массы и жёсткости → КЭ-модель → независимая проверка по эксперименту → идентификация нагрузки → механика тормоза → сравнение схем размещения.

## Ключевые результаты

- КЭ-модель по сечениям 3D-модели независимо от эксперимента даёт f₁ = 69,0 Гц при жёстких стыках. Измеренные 64,18 ± 0,04 Гц получаются при жёсткости фланцевых стыков 12–28 ГН/м. Сходимость по сетке и шагу по времени: изменения < 0,3 %.
- Повторная обработка опыта 1: α = 5,98 ± 0,24 с⁻¹, ζ = 0,0148. Асимметрия полупериодов объясняется дрейфом (формула 4β/ω). 23 мм — перемещение к 200 мс; откат не завершён, полный откат по расчёту 35–50 мм.
- Эквивалентные газодинамические импульсы: 12,5 кН·с (начало 47,9 мс; совпадает с отметкой D1) и 10,5 кН·с.
- Тормоз (3 пакета × 6 тарельчатых пружин 32×14×3,0×0,7): 17,0 кН нормальной силы на 1 мм сжатия пакета. Эффективное усилие в опытах 2–3 — 30–37 кН на всю установку (при допущении одинакового нагружения), что ≪ 3,1 МН в стыке ПС3–ФК.
- Коэффициенты эффективности сухого трения η(r) = (2/π)·arcsin r и κ(r) = √(1−r²): станция у узла первой формы (S3) останавливает откат, станции в пучностях (S1, S5) гасят колебания.
- Рекомендуемое распределение усилий S1 : S2 : S3 ≈ 0,48 : 0,18 : 0,32 при F_Σ ≥ 60 кН. Это расчётная рекомендация; её нужно проверить в испытаниях.

Раздел 8 статьи (таблица 8) сводит основные результаты и способ их независимой проверки.

## Принятые допущения (не данные)

- ρ = 7850 кг/м³ для всех деталей; E = 206 ГПа, ν = 0,3.
- Суммарный коэффициент трения тормоза μ_Σ = μ₁ + μ₂ задан диапазоном 0,3–0,8, так как материал фрикционной пластины неизвестен.
- Газодинамическая нагрузка аппроксимирована двумя импульсами sin² (казённая часть и форкамера) и восстановлена по X_ФК(t) опыта 1. Эти импульсы эквивалентные, а не измеренные давления.
- Зависимость X_ФК(t) опыта 1 переведена в числовой ряд по рисунку 4 скриптом `calc/digitize.py` (контроль: 18 подписанных экстремумов, отклонение ≤ 0,21 мс).

## Воспроизведение

```bash
pip install numpy scipy matplotlib python-docx lxml cadquery-ocp
# 1) CAD (нужен исходный STEP-файл, в репозиторий НЕ включён): положить его как cad/model.stp

# 3) статья
cd ../doc_build && python3 article.py
```
